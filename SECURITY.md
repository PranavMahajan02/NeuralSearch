# Security policy

## Reporting a vulnerability

Please do **not** open a public issue. Report privately through GitHub's
**"Report a vulnerability"** (Security → Advisories) on this repository, or by e-mail to the
maintainer (the address in the git history), with steps to reproduce and the impact.
You should get an answer within 7 days. Test only against your own deployment.

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | yes |
| < 1.0 | no |

## Details

The threat model, the controls mapped to threats, known gaps, the secret-rotation procedure,
